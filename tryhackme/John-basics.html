Task 2: Basic Terms

What are Hashes?

A hash converts data of any length into a fixed-length value using a hashing algorithm. This process hides the original data.

"polo" → MD5 hash: b53759f3ce692de7aff1b5779d3964da
"polomints" → MD5 hash: 584b6e4f4586e136bc280f27f9c64f3b

What Makes Hashes Secure?

Hashes are one-way functions — easy to compute but extremely hard to reverse. This relates to the P vs NP concept:

  • P (Polynomial Time): Problems that can be solved quickly.
  • NP (Non-deterministic Polynomial Time): Problems where verifying a solution is easy, but finding it is hard.

Hashing falls under P, while “un-hashing” is NP-hard, making it computationally infeasible.

Where John Comes In

Although hashes can’t be reversed directly, they can be cracked using a dictionary attack. John the Ripper (John) compares hashes of dictionary words with the target hash to find matches.

Answer: Jumbo John

Task 4: Cracking Basic Hashes

Basic syntax:

john [options] [file path]

Automatic cracking example:

john --wordlist=/usr/share/wordlists/rockyou.txt hash_to_crack.txt

Format-specific example:

john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hash_to_crack.txt

Answers:

  • hash1.txt → md5 → biscuit
  • hash2.txt → sha1 → kangeroo
  • hash3.txt → sha256 → microphone
  • hash4.txt → whirlpool → colossal

Task 5: Cracking Windows Authentication Hashes

Format: NTLM / NTHash, stored in SAM database.

Use:

john --wordlist=/usr/share/wordlists/rockyou.txt --format=NT ntlm.txt

Answer: mushroom

Task 6: Cracking /etc/shadow Hashes

Combine passwd and shadow with unshadow:

unshadow [path to passwd] [path to shadow] > unshadowed.txt

Crack:

john --wordlist=/usr/share/wordlists/rockyou.txt --format=sha512crypt unshadowed.txt

Answer: 1234

Task 7: Single Crack Mode

john --single --format=raw-sha256 hashes.txt

Answer: Jok3r

Task 8: Custom Rules

Custom rules allow you to exploit password complexity predictability.

Example to add capitals at the end: Az"[A-Z]"

Answer: Password complexity predictability, --rule=THMRules

Task 9: Cracking Password-Protected Zip Files

zip2john secure.zip > zip_hash.txt
john --wordlist=/usr/share/wordlists/rockyou.txt zip_hash.txt

Answer: pass123, flag: THM{w3ll_d0n3_h4sh_r0y4l}

Task 10: Cracking Password-Protected RAR Archives

rar2john secure.rar > rar_hash.txt
john --wordlist=/usr/share/wordlists/rockyou.txt rar_hash.txt

Answer: password, flag: THM{r4r_4rch1ve5_th15_t1m3}

Task 11: Cracking SSH Keys with John

ssh2john id_rsa > id_rsa_hash.txt
john --wordlist=/usr/share/wordlists/rockyou.txt id_rsa_hash.txt

Answer: mango
